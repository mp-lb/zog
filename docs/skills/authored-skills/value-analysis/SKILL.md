# Value Analysis

## Workflow

1. Ask for source material if the user has not provided enough context.
2. Prefer source code, product docs, designs, landing pages, pitch decks, testimonials, and existing positioning notes.
3. Read `references/index.md` to choose the analysis track.
4. Read `references/inputs.md` when requesting or evaluating input material.
5. Read `references/marketing-positioning.md` for positioning work.
6. Produce direct strategic output. Avoid generic marketing advice.
7. Ask for user feedback only when the next decision depends on product reality the available inputs do not show.

## Output Rules

- Be specific to the product and market.
- Name the alternative behaviors buyers already use.
- Separate evidence from inference.
- Prefer concrete positioning language over frameworks.
- Do not write introductory filler.
